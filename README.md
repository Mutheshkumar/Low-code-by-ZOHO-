## 📖 About the Course

**Course:** Low-Code Application Development  
**Platform:** Zoho Creator (Low-Code / No-Code Platform)

## 🚀 How to Use

1. **Clone the Repository**
   ```bash
   git clone https://github.com/Mukilan-s18/Low-Code-Zoho-Creator.git
   cd Low-Code-Zoho-Creator
   ```

2. **Access Zoho Creator**  
   Sign in or create a free account at [zoho.com/creator](https://www.zoho.com/creator/)

3. **Follow Experiments Sequentially**  
   Open each experiment file (`Exp-01` → `Exp-15`) and follow the step-by-step instructions

4. **Implement on Zoho Creator**  
   Apply the concepts learned in each experiment directly in your Zoho Creator workspace

## 💡 Key Concepts Covered

### 🔷 Low-Code Fundamentals
- Visual drag-and-drop development
- Form design and field configuration
- Application lifecycle management

### 🔷 Deluge Scripting Language
- Variable types and operators
- Conditional statements and loops
- Built-in functions (string, date, math, list)
- Record operations: `input`, `zoho.creator.getRecords`, `zoho.creator.addRecord`

### 🔷 Automation & Workflows
- Event-driven workflows (on create, on edit, on delete)
- Scheduled functions (cron jobs)
- Approval processes and multi-step workflows

### 🔷 Data Management
- One-to-many and many-to-many relationships
- Lookup fields and subforms
- Data import (CSV, Excel) and export
- Report generation and dashboards

### 🔷 Integration & Security
- REST API integration with external services
- Webhook configuration
- Role-based access control
- Field-level security and sharing rules
